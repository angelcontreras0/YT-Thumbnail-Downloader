# ThumbGrab

Una herramienta simple para obtener y descargar miniaturas de videos de YouTube pegando una URL.

## Probar la web

👉 https://angelcontreras0.github.io/YT-Thumbnail-Downloader/

## Funciones

- Soporta URLs normales de YouTube.
- Soporta `youtu.be`.
- Soporta YouTube Shorts.
- Detecta varias resoluciones disponibles.
- Permite abrir o descargar cada miniatura.
- Sin anuncios, popups, cuentas ni backend.
- Funciona como sitio estático en GitHub Pages.

## Publicar en GitHub Pages

1. Ve a **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona `main` y `/ (root)`.
4. Guarda.

## Nota

Proyecto vibecodeado por diversión. No está afiliado con YouTube.
